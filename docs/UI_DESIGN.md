# AROH UI/UX

## Design Philosophy

Situation → Risk → Evidence → Context

The application is designed for drilling engineers,
geologists and drilling managers.

It should feel like an industrial decision-support
system, not a generic AI chatbot.

---

# Navigation

1. Command Center
2. Active Well
3. Offset Explorer
4. Correlation
5. Knowledge
6. Copilot

---

# Command Center

Display:

- Active wells
- High-risk wells
- Current alerts
- Data health
- Current drilling activity

---

# Active Well

Display:

- Current depth
- Formation
- ROP
- WOB
- RPM
- Torque
- Mud weight
- Pressure

---

# Risk Ahead

Show:

Risk type
Risk score
Risk interval
Confidence
Supporting wells
Historical event count

---

# Colors

Green = Normal
Yellow = Watch
Orange = Elevated
Red = Critical

Colors should communicate meaning.

---

# Visual Style

Professional
Industrial
Minimal
Modern
High information density
Readable

Avoid:

- excessive gradients
- excessive animation
- gaming aesthetics
- giant chatbot interface
- unnecessary decorative elements

---

# Main UX Rule

A critical alert should be understandable within
a few seconds.

The user should immediately understand:

WHAT?
WHERE?
WHY?
EVIDENCE?
